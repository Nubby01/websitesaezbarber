# Academia SB — websiteSaezBarber

Sitio web de Academia SB (metodología de visagismo SaezBarber).

## Stack

React 19 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion · Leaflet · Lenis

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy en Vercel

1. Entrá a [vercel.com](https://vercel.com) e iniciá sesión con GitHub.
2. **Add New Project** → importá `Nubby01/websitesaezbarber`.
3. Framework: **Vite**. Build command: `npm run build`. Output: `dist`.
4. Deploy. Las rutas SPA ya están configuradas en `vercel.json`.
