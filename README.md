# Academia SB — websiteSaezBarber

Sitio web de Academia SB (metodología de visagismo SaezBarber).

## Stack

React 19 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion · Leaflet · Lenis

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
